## Overview
**HolaSQL** - is an inheritor of T-SQL and is used in HolaDB.

For the simplicity the language is made **case-insensitive**.

## Currently supported features

- DQL (SELECT, FROM, WHERE)
- Expressions (=, !=, >, <, >=, <=)
- Logical operators (AND, OR, NOT)
- Literals (INT, STRING, NULL)
- Data Types (INT, VARCHAR(n))
- Additionally (*, braces)
